# Royal Road Kindle Tools cleanup queue template.
# Add one TYPE|VALUE entry per retired artifact in future releases.
# DOC|name                 removes one exact file from /mnt/us/documents
# DOCGLOB|pattern          removes matching files in /mnt/us/documents (no subdirectories)
# PKG|relative/path        removes one exact file from the installed KPM package cache
# PKGDIR|relative/path     removes a directory only when it is empty
# REMOTE_DELETE|filename  deletes a saved pasters.io paste using its local delete URL
# BOOKMARK|title           removes only the named project test JavaScript bookmark
#
# The installer merges these entries into the Kindle's pending queue.
# The cleaner removes an entry from that queue only after deletion is verified.
# Completed entries are recorded locally so later updates do not re-add them.
#
