# Optional Kindle Batch Preparation repair

This folder is outside the regular KPM package. KPM-Update-All does not install, repair, or update this plugin.

It contains the manual `KindleBatchPrepareFix.sh` launcher, matching `kindle_batch_prepare_main.lua.gz` source archive, and developer-side `patch_batch_controls.py` helper.

For a manual repair, copy the launcher and archive to Kindle Documents, rename the archive to `KindleBatchPrepare-main.lua.gz`, and run the shell launcher. Nothing here runs automatically. A previously installed KOReader plugin is not removed by the regular package.
